# 🛰 AtronixX-Core

شبیه‌سازی Termius داخل تلگرام: ترمینال SSH زنده، مدیریت فایل (SFTP)، مانیتورینگ سرور، اسنیپت،
گروه‌بندی سرورها، پنل مدیریت کامل، مود رایگان/اشتراکی، بکاپ و ریستور رمزگذاری‌شده — همه داخل داکر
و در یک پوشه‌ی کاملاً مجزا از بقیه‌ی سرویس‌های سرور.

## ⚡ نصب سریع

```bash
git clone https://github.com/<owner>/<repo>.git
cd <repo>
sudo ./install.sh <owner>/<repo>
```

اسکریپت Docker را (در صورت نبود) نصب می‌کند، پروژه را در `/opt/atronixx-core` قرار می‌دهد،
توکن بات/آیدی ادمین/رمز بکاپ را می‌پرسد، و بات را بالا می‌آورد. بعد از نصب:

```bash
atronixx status     # وضعیت
atronixx logs        # لاگ زنده
atronixx restart      # ری‌استارت
atronixx update       # دریافت نسخه‌ی جدید و بالا آوردن
atronixx uninstall    # حذف کامل (فقط همین پروژه، بدون تأثیر روی بقیه‌ی سرور)
```

## 🔧 تنظیمات (`.env`)

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن از @BotFather |
| `ADMIN_ID` | آیدی عددی تلگرام ادمین (تنها ادمین ربات) |
| `SUPPORT_USERNAME` | یوزرنیم پشتیبانی که به کاربران بدون اشتراک نشان داده می‌شود |
| `BACKUP_PASSPHRASE` | رمز بکاپ خودکار (AES-256) — جایی یادداشتش کن، قابل بازیابی نیست |
| `TZ` | منطقه‌ی زمانی (پیش‌فرض Asia/Tehran) |
| `BACKUP_INTERVAL_HOURS` | فاصله‌ی بکاپ خودکار (پیش‌فرض ۲۴) |
| `MAX_LIVE_SESSIONS` | سقف نشست ترمینال هم‌زمان (از پنل ادمین هم قابل تغییر) |
| `IDLE_TIMEOUT_MIN` / `MAX_SESSION_HOURS` | تایم‌اوت بیکاری و حداکثر عمر هر نشست |
| `BLOCKED_IPS` | آیپی‌های اضافی برای بلاک (کاما جدا) |

## 🛡 امنیت (خلاصه)

- پسورد/کلید SSH با **AES-256-GCM** رمزنگاری می‌شوند؛ کلید اصلی در فایل جدا (`secret.key`, دسترسی 600)
  داخل ولوم `/data` نگه‌داری می‌شود، نه در دیتابیس.
- پیام‌های حاوی پسورد/کلید بلافاصله از چت پاک می‌شوند.
- قبل از هر اتصال، مقصد resolve و آیپی‌های داخلی/خصوصی/لوکال/متادیتای ابری و آیپی خود سرور بلاک می‌شوند (ضد SSRF).
- کلید میزبان با مدل TOFU تأیید می‌شود؛ تغییر کلید هشدار امنیتی صریح نشان می‌دهد.
- کانتینر با کاربر غیر-root، فایل‌سیستم read-only (به‌جز `/tmp` و ولوم `/data`)، بدون پورت باز،
  و در شبکه‌ی داکر اختصاصی اجرا می‌شود؛ سقف CPU/RAM جدا از بقیه‌ی سرویس‌های سرور.
- بکاپ‌ها با رمز جداگانه (scrypt + AES-256-GCM) رمزگذاری می‌شوند.

## 🧪 تست منطق داخلی (بدون تلگرام/SSH واقعی)

```bash
pip install -r requirements.txt --break-system-packages
python3 tests/test_core.py       # رمزنگاری، دیتابیس، اشتراک، بکاپ/ریستور، تاریخ شمسی، امنیت مقصد
PYTHONPATH=tests/stubs:. python3 tests/test_routing.py   # تطبیق همه‌ی دکمه‌ها با هندلرهای ثبت‌شده
python3 tests/scan_strings.py    # همه‌ی کلیدهای رشته موجودند و placeholderها کامل‌اند
```

⚠️ این تست‌ها منطق داخلی را با قطعیت بررسی می‌کنند، اما اتصال واقعی به تلگرام و SSH را
شبیه‌سازی نمی‌کنند (چون از این محیط به تلگرام/سرور شما دسترسی نیست). **چک‌لیست تست دستی**
در `TESTING.md` را بعد از نصب روی سرور واقعی انجام بده.

## 📁 ساختار پروژه

```
config.py            تنظیمات از .env
main.py              نقطه‌ی ورود، ثبت هندلرها
core/                رمزنگاری، امنیت مقصد، موتور SSH/SFTP، ثبت نشست‌ها، بکاپ، کارهای پس‌زمینه
database/db.py       SQLite (WAL)
handlers/            منطق UI: start، gate (دروازه‌ی دسترسی)، hosts، terminal، sftp، tools، admin، router
locales/             رشته‌های فارسی/انگلیسی
tests/               تست منطق داخلی + استاب‌های تلگرام برای تست مسیریابی
```
